## Event definitions
- **DOT START**: first green dot of a run -> LONG (red -> SHORT) (shorts = the mirror)
- **DOT 3RD**: the 3rd green dot in a row -> LONG (trend confirmed) (shorts = the mirror)
- **DOT 5TH**: the 5th green dot in a row -> LONG (shorts = the mirror)
- **DOT 10TH**: the 10th green dot in a row -> LONG (late) (shorts = the mirror)
- **EVERY DOT**: every candle with a green dot -> LONG (is being 'in the dots' good?) - 1 in 4 sampled (shorts = the mirror)
- **DOTS END**: the first candle after a green run ends -> SHORT (does the move stop when the dots stop?) (shorts = the mirror)
- **BLUE START**: first blue dot (greed maxed) -> LONG (follow; a minus = fade it) (shorts = the mirror)
- **BLUE + GREEN**: first candle with a blue AND a green dot -> LONG (shorts = the mirror)
- **DIAMOND**: green diamond -> LONG, red diamond -> SHORT (shorts = the mirror)
- **DIAMOND + DOT**: first green dot within 5 candles after a green diamond -> LONG (shorts = the mirror)
- **ORANGE -> GREEN**: first green dot within 10 candles after fear was maxed (orange) -> LONG (bottom confirmed) (shorts = the mirror)
- **TTM ONLY**: TTM background turns green (no Vix Fix) -> LONG - to see what the agreement adds (shorts = the mirror)
- **VIX ONLY**: Vix Fix up flow starts (no TTM) -> LONG - to see what the agreement adds (shorts = the mirror)

**Luck check:** this exact test was run 4 times on random prices that move together like SPY / QQQ / IWM (520 t values each): the luckiest positive t was 2.2-3.0, the most negative -2.3 to -4.3, and nothing passed HELD UP. So a lone t of 3-4 can be luck; HELD UP needs t 3.5+ AND both halves AND every symbol AND positive neighbors. A chart full of dots that look right is not evidence: the eye remembers the runs that worked.
