## Event definitions
- **TL GREEN START**: the trend line turns GREEN -> LONG (the trend line alone - the baseline) (shorts = the mirror)
- **DOT START + TL GREEN**: first green dot while the trend line is GREEN -> LONG (full confluence) (shorts = the mirror)
- **DOT START + TL UP**: first green dot while the trend line is green or blue -> LONG (shorts = the mirror)
- **DOT START AGAINST TL**: first green dot while the trend line is RED / pink -> LONG (against the line) (shorts = the mirror)
- **DOT START + TL GREEN + 23 DEG**: first green dot, trend line GREEN and its angle 23+ degrees -> LONG (shorts = the mirror)
- **EVERY DOT + TL GREEN**: every candle with a green dot AND a green trend line -> LONG - 1 in 4 sampled (shorts = the mirror)
- **TL GREEN + DOT IN 3**: the trend line turns GREEN with a green dot on that candle or the 2 before -> LONG (shorts = the mirror)
- **DIAMOND + TL GREEN**: green diamond while the trend line is GREEN -> LONG (a pullback low inside an uptrend) (shorts = the mirror)
- **DIAMOND AGAINST TL**: green diamond while the trend line is RED / pink -> LONG (calling the bottom against the line) (shorts = the mirror)
- **DIAMOND + DOT + TL GREEN**: first green dot within 5 candles after a green diamond, trend line GREEN -> LONG (shorts = the mirror)
- **ORANGE -> GREEN + TL GREEN**: first green dot within 10 candles after fear was maxed, trend line GREEN -> LONG (shorts = the mirror)

**Luck check:** this exact test was run 4 times on random prices that move together like SPY / QQQ / IWM (520 t values each): the luckiest positive t was 2.2-3.0, the most negative -2.3 to -4.3, and nothing passed HELD UP.
